## 2. Dataset structure

CIC-IDS2017 captures network traffic over 5 days and distributes it as:

| Archive | Contents |
|---------|----------|
| `GeneratedLabelledFlows.zip` | Labeled flow CSV files (one per day/session), produced by CICFlowMeter |
| `PCAPs.zip` | Raw packet capture (PCAP) files corresponding to each CSV |
| `MachineLearningCSV.zip` | Alternative packaging of the labeled flow CSVs |

### Extracted file layout

```
CIC-IDS2017/
├── GeneratedLabelledFlows/
│   ├── Monday-WorkingHours.pcap_ISCX.csv
│   ├── Tuesday-WorkingHours.pcap_ISCX.csv
│   ├── Wednesday-workingHours.pcap_ISCX.csv
│   ├── Thursday-WorkingHours-Morning-WebAttacks.pcap_ISCX.csv
│   ├── Thursday-WorkingHours-Afternoon-Infilteration.pcap_ISCX.csv
│   ├── Friday-WorkingHours-Morning.pcap_ISCX.csv
│   └── Friday-WorkingHours-Afternoon-DDos.pcap_ISCX.csv
└── PCAPs/
    ├── Monday-WorkingHours.pcap
    ├── Tuesday-WorkingHours.pcap
    ├── Wednesday-workingHours.pcap
    ├── Thursday-WorkingHours-Morning-WebAttacks.pcap
    ├── Thursday-WorkingHours-Afternoon-Infilteration.pcap
    ├── Friday-WorkingHours-Morning.pcap
    └── Friday-WorkingHours-Afternoon-DDos.pcap
```

Each CSV row is one bidirectional network flow with ~78 numeric features plus a `Label` column. Each PCAP is the raw capture from which the corresponding CSV was derived.

---

## 3. CSV and PCAP availability

- **CSV (labeled flows):** Yes — distributed inside `GeneratedLabelledFlows.zip` / `MachineLearningCSV.zip`. This is the primary format used for ML training in SentinelGraph.
- **PCAP (raw packets):** Yes — distributed inside `PCAPs.zip`. Useful for re-extracting flows or packet-level analysis. SentinelGraph v1.0 uses the CSV flow representation; PCAP support is out of v1.0 scope.

## 4. Traffic collection dates

| Day | Date | Description |
|-----|------|-------------|
| Monday | July 3, 2017 | Normal (benign) activity only — baseline traffic |
| Tuesday | July 4, 2017 | Brute Force FTP + Brute Force SSH + normal |
| Wednesday | July 5, 2017 | DoS variants + Heartbleed + normal |
| Thursday | July 6, 2017 | Web Attacks + Infiltration + normal |
| Friday | July 7, 2017 | Botnet + PortScan + DDoS + normal |

Capture window: 9:00 AM – 5:00 PM local time each day. Total duration: 5 days.

| Day | Attack categories |
|-----|-------------------|
| Monday | — (Benign only) |
| Tuesday | FTP-Patator (Brute Force FTP), SSH-Patator (Brute Force SSH) |
| Wednesday | DoS Hulk, DoS GoldenEye, DoS slowloris, DoS Slowhttptest, Heartbleed |
| Thursday | Web Attack – Brute Force, Web Attack – XSS, Web Attack – SQL Injection, Infiltration |
| Friday | Bot, PortScan, DDoS |

**Label space:**
- **Binary:** `BENIGN` vs `Attack` (any attack category)
- **Multiclass:** 15 categories — `BENIGN` + 14 attack types

## 9. SHA-256 checksum verification

SentinelGraph does not distribute dataset files, so no checksums are published here. After downloading `GeneratedLabelledFlows.zip`, `PCAPs.zip`, or `MachineLearningCSV.zip`, compute and record the SHA-256 checksum in `data/manifests/cic-ids2017.json`:

```bash
sha256sum GeneratedLabelledFlows.zip PCAPs.zip MachineLearningCSV.zip
```

The acquisition script (`scripts/data/acquire_cic_ids2017.py`) automates this verification and records results in the manifest.

## 10. Known dataset limitations

| Limitation | Description |
|------------|-------------|
| **Registration wall** | Official download requires filling a web form; no direct programmatic download URL. |
| **NaN / Infinity values** | Raw CSVs contain missing or infinite values that must be cleaned before training. |
| **Duplicate columns** | Some CSV exports contain duplicate `Fwd Header Length` columns. |
| **Identifier leakage** | Raw CSVs include Flow ID, IPs, ports, and Timestamp; these must be dropped or handled to avoid shortcut learning. |
| **Label inconsistency** | The Engelen et al. (2021) "Troubleshooting" study found mislabeled traces and proposed corrected labeling; original and corrected labels may differ. |
| **Class imbalance** | Benign traffic vastly outnumbers most attack categories (e.g., Heartbleed has only 11 flows). |
| **Single network trace** | All traffic comes from one enterprise-like topology over 5 days; may not generalize to other networks. |
| **Attack tool specificity** | Attacks were simulated with specific tools/configurations; models may not generalize to other variants. |

## 11. Kaggle compatibility

Kaggle notebooks can attach the CIC-IDS2017 dataset via Kaggle's dataset URL mechanism. The acquisition script supports Kaggle by:

1. Accepting a local path to already-downloaded ZIP/CSV files (e.g., from Kaggle dataset attachment under `/kaggle/input/`).
2. Verifying SHA-256 checksums against `data/manifests/cic-ids2017.json`.
3. Writing verified outputs to `/kaggle/working/` (Kaggle's writable output directory).

See `scripts/data/acquire_cic_ids2017.py` for usage.
