# SentinelGraph Dashboard

React + TypeScript frontend scaffold for SentinelGraph.

## Run

```bash
npm install
npm run dev
```

The dashboard is intentionally a minimal scaffold — no dashboard features are
implemented in this issue (SG-001). Dashboard views are implemented in later
issues (SG-043 and beyond).

## Scripts

- `npm run dev` — start the Vite dev server
- `npm run build` — type-check and build for production
- `npm run lint` — run ESLint
- `npm run typecheck` — run TypeScript type checking
- `npm run preview` — preview the production build
